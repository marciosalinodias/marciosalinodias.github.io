# marciosalinodias.github.io

Portfólio de **Marcio Salino Dias** — Tech Lead, Arquitetura de Software e IA.

Publicado em https://marciosalinodias.github.io (GitHub Pages, branch `master`, raiz).

Site estático (HTML + CSS + JS, sem framework). Para rodar localmente:

```bash
npm run dev   # http://localhost:5173
```

A pasta `Dojo/` guarda as apresentações antigas (HTML e CSS).

A vitrine inclui handoff-it, Public-it, ApexCode e Twin Games. As capturas reais ficam em `assets/`, com origem registrada em `assets/sources.json`. A apresentação da trajetória destaca construção e evolução de produtos, sistemas e plataformas, sem limitar a experiência a uma quantidade de produtos de uma empresa.
